# Changelog

## 1.0.0

- Каталог пиццы, адаптивная вёрстка, закреплённая шапка и активная навигация.
- Конструктор размера, теста, добавок и исключений ингредиентов.
- Сохраняемая корзина с миграцией данных, редактором и объединением вариантов.
- Пошаговое оформление, маска телефона, комментарий и демонстрационная оплата.
- Выбор города/филиала, геолокация по кнопке, карта и адресные подсказки.
- Серверный прокси Яндекса с ограничением запросов.
- Unit- и браузерные тесты, проверки доступности, линтер, TypeScript и CI.
