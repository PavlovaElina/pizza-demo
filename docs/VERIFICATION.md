# Проверки

## Автоматические проверки

Команда npm run check выполняет ESLint, unit-тесты, проверку TypeScript и production-сборку. Команда npm run test:e2e запускает браузерные тесты. GitHub Actions выполняет обе команды при push и pull request.

Последняя локальная проверка: 8 ноября 2026. Результаты: 19 unit-тестов и 52 браузерных теста в desktop/mobile Chromium. Адресные сервисы и SDK в автотестах подменяются; действующие ключи не требуются и квоты Яндекса не расходуются.

Проверяемые сценарии:

- Восстановление и миграция корзины, идентификаторы вариантов, исключения ингредиентов, пересчёт и объединение без потери количества.
- Оформление, комментарий, сведения адреса, способы оплаты и отсутствие карточных реквизитов в API/browser storage.
- Выбор города/филиала, подтверждение геолокации, отказ, таймаут и неподдерживаемый город.
- Смена города с сохранением контактов и сбросом адреса.
- Клик по карте, перенос метки, поиск адреса, несовпадение города и ответы в неправильном порядке.
- Подсказки, задержка ввода, клавиатура и ошибки сервисов без блокирования ручного адреса.
- Маска телефона, адаптивность, активная навигация и проверки axe в основных состояниях.
- Нормализация серверных ответов, отказ upstream и восстановление бюджета ограничения запросов.

## Реальная интеграция

На localhost с действующими ключами проверены загрузка настоящей карты, адресные подсказки и выбор адреса с геокодированием и меткой. Это не заменяет проверку всей интеграции после изменения ключей, ограничений или домена. Сценарии отказа/таймаута геолокации и геокодера проверяются автоматическими подменами.

## Практические ограничения

Не выполнена отдельная матрица Safari/Firefox/VoiceOver, реальной экранной клавиатуры, масштаба 200–400% и Lighthouse. Проверки Chromium и axe не гарантируют отсутствие всех ошибок доступности.

Филиалы, цены и контакты вымышленные. Реальная зона доставки, банк, списания и серверное хранение заказов отсутствуют. MSW не является защищённым backend. Без геокодера фактическое положение вручную введённого дома не подтверждается.

Общий лимит адресного API защищает один процесс демонстрации; после перезапуска счётчик сбрасывается. Для публичной нагрузки нужны ограничения и наблюдение на уровне инфраструктуры.
