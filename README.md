# Pizza Cheff

[Открыть демо](https://pizza-cheff-demo.onrender.com/)

Демонстрационный сайт пиццерии на React и TypeScript: каталог, настройка состава, корзина, пошаговое оформление и имитация оплаты. Филиалы, контакты, цены и условия вымышленные. Настоящих заказов, доставки и списаний нет.

## Возможности

- Размер, тип теста, дополнительные и исключённые ингредиенты.
- Редактирование пиццы в корзине, объединение одинаковых вариантов, ограничение 99 штук на вариант.
- Сохранение корзины с проверкой данных и миграцией предыдущих версий.
- Контактные данные, маска телефона, комментарий и дополнительные сведения адреса.
- Выбор города и филиала, геолокация по запросу пользователя.
- Яндекс Карты, адресные подсказки, выбор точки и обратное геокодирование.
- Оплата при получении или локальная имитация оплаты картой.
- Адаптивный интерфейс, управление с клавиатуры и поддержка reduced motion.

## Требования и запуск

Нужен Node.js 24 или новее и npm.

```sh
npm ci
cp .env.example .env.local
npm run dev
```

Заполните ключи в .env.local по инструкции [Яндекс Карты](docs/MAPS.md). Без ключей доступны ручной выбор города и ввод адреса; работающая карта не имитируется.

Сайт: http://localhost:5173. Команда запускает Vite и Node.js API вместе; остановка — Ctrl+C. На macOS также доступен scripts/start.command.

Для показа собранного сайта на macOS используйте scripts/serve.command: сервер откроется на http://localhost:3003. Доступ с других устройств описан в [HOSTING.md](docs/HOSTING.md).

## Структура

```text
src/
  components/       интерфейс и диалоговые окна
  data/             ингредиенты, варианты пиццы, города и филиалы
  hooks/            корзина и активная навигация
  services/         HTTP-клиенты и адаптер карты
  mocks/            демонстрационный API каталога и заказов
  utils/            расчёты, валидация и unit-тесты
  styles/           стили, адаптивность и анимации
  App.tsx           сборка экрана
  main.tsx          точка входа
  types.ts          типы предметной области
public/assets/      изображения и шрифты
server/             адресный API и его unit-тесты
scripts/            совместный запуск процессов
tests/e2e/          пользовательские сценарии и тестовые подмены
docs/               архитектура, интеграции и инструкции
.github/workflows/  автоматические проверки
```

Компоненты используют PascalCase, хуки — useSomething, ресурсы — kebab-case. Файлы конфигурации сохраняют стандартные имена инструментов.

## Архитектура и данные

useCart управляет корзиной через reducer. Идентификатор варианта включает пиццу, размер, тесто, отсортированные начинки и исключения. Исключение ингредиента не снижает цену. При редактировании меняется всё количество позиции; объединение сверх 99 блокируется без потери товаров.

OrderDialog переключает этапы cart → checkout → payment → success. Нативный dialog ограничивает фокус и поддерживает Escape. Поля сохраняются при переходах назад внутри окна. Закрытие окна сбрасывает контактные данные; успех очищает корзину, ошибка позволяет повторить действие.

MSW имитирует HTTP-каталог и заказы в браузере. Это демонстрация API-контракта, а не полноценный backend или граница безопасности. Адресные запросы обслуживает отдельный Node.js-сервис с серверными ключами Яндекса.

В localStorage сохраняются только варианты корзины и идентификаторы города/филиала. Контакты, адрес, комментарий, координаты пользователя и карточные реквизиты туда не записываются. Карточные реквизиты не отправляются в API; для демонстрации используйте вымышленные данные.
